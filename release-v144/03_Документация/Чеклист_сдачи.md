## Запуск и границы

- Windows: `02_Приложение/Запустить приложение.bat`; нужны Python 3 и Pillow из `requirements.txt`.
- Телефон: см. `02_Приложение/Руководство_пользователя.md`. По локальной сети обычный HTTP позволяет открыть сайт, но не даёт безопасного контекста для установки PWA/Service Worker; для этого нужен HTTPS с доверенным сертификатом.
- Публичный хостинг, аккаунты и облачная синхронизация не включены.
- Повторная проверка архива: `04_QA_доказательства/verify_submission_package.py --package-dir <папка> --archive <zip>`.
