# Руководство пользователя folio

Это локальное рабочее пространство для проектов и портфолио. Пользовательские карточки хранятся на устройстве: в настольной версии — в SQLite, в браузерной версии — в IndexedDB. Между ними нет автоматической синхронизации. Для переноса используйте JSON-резервную копию.

## Быстрый старт на компьютере

1. Установите Python 3. Если Pillow ещё не установлен, откройте PowerShell в папке приложения и выполните `python -m pip install -r requirements.txt`.
2. Запустите `Запустить приложение.bat` либо `python main.py`.
3. При первом запуске папка приложения должна быть доступна для записи: рабочая база `portfolio_data.sqlite3` создаётся рядом с `main.py`. Если там уже есть `portfolio_data.json`, приложение переносит его в SQLite и оставляет исходный JSON на месте. Если нет ни SQLite, ни JSON, приложение создаёт базу с тремя демонстрационными кейсами; просмотрите их и замените или удалите перед внесением своих работ.
4. Если меню «Файл» предлагает базу и JSON, выбирайте SQLite для обычной работы. Используйте JSON для переноса и резервных копий.

В карточке проекта заполняйте название и короткое описание; остальные поля можно добавить позже. «Контекст задачи», «Решение», «Этапы работы», «Моя роль», «Результат» и метрики помогут оформить кейс для портфолио. Для лендинга указывается число страниц; для веб-приложения доступны репозиторий и серверный стек. Обложка: PNG, JPEG или WebP до 2 МиБ; файл остаётся локальным.

В веб-форме теги отображаются отдельными чипами: нажмите Enter или «Добавить», чтобы внести тег; несколько тегов можно вставить через запятую. Начните вводить существующее значение, чтобы увидеть подсказки. Повторяющиеся теги объединяются без учёта регистра; каждый тег ограничен 32 символами, всего можно добавить до 20. Удалить отдельный тег можно кнопкой × на чипе. Настольная форма по-прежнему принимает список через запятую. В обеих версиях и JSON-резервной копии сохраняется прежний формат массива `tags`.

В форме проекта кнопка «Отмена» и клавиша Escape закрывают окно без сохранения; Ctrl+Enter сохраняет карточку. При открытии формы курсор сразу установлен в поле названия. На небольшом экране перемещайтесь по длинной форме колесом мыши или полосой прокрутки; при переходе клавишей Tab активное поле прокручивается в видимую область. Если при редактировании сменить тип проекта, перед сохранением появится предупреждение, когда поля прежнего типа (репозиторий, серверный стек или число страниц) не войдут в новую модель. Можно отменить преобразование и вернуть прежний тип; пока предупреждение не подтверждено, исходная запись не меняется.

Форма профиля автора также прокручивается на небольшом экране; кнопки отмены и сохранения остаются видимыми. Окно выбора стратегии импорта JSON подбирает стартовую высоту по разрешению монитора.

В таблице выберите проект, чтобы увидеть его карточку. Команды «Добавить», «Изменить», «Дублировать», «Удалить» и перемещение выше/ниже относятся к выбранной записи. Для проверки поиска начните с названия или технологии; фильтры можно сочетать, а «Сбросить» возвращает полный список. Избранное отмечает кейсы для витрины.

Если библиотека пуста, в списке появится иллюстрация и кнопка добавления первого кейса. Если поиск или фильтры не нашли подходящие записи, выберите «Сбросить фильтры» или измените запрос.

## Запуск браузерной версии на компьютере и телефоне

1. Запустите `web\\Запустить веб-версию.bat` на компьютере с Python 3. Сервер доступен в локальной сети на порту `8765`.
2. На компьютере откройте `http://127.0.0.1:8765/`.
3. Для телефона подключите оба устройства к одной Wi-Fi сети. На компьютере выполните `ipconfig`, найдите IPv4-адрес активного Wi-Fi адаптера и откройте на телефоне `http://АДРЕС-КОМПЬЮТЕРА:8765/`. Если Windows спросит о доступе Python к частной сети, разрешите его для частной сети.
4. Телефону нужен IP-адрес компьютера, а не `127.0.0.1`: на телефоне этот адрес указывает на сам телефон. Не публикуйте адрес локальной сети в интернете.
5. На каждом устройстве и в каждом браузере веб-версия хранит отдельную библиотеку. Чтобы начать работу на телефоне, импортируйте JSON из настольной версии через «Настройки и данные». После редактирования экспортируйте JSON на телефоне и импортируйте его на компьютере.

Офлайн-кэш оболочки и установка PWA доступны в защищённом контексте. На компьютере адрес `http://127.0.0.1:8765/` считается локальным защищённым контекстом: после первого открытия приложение может кэшировать оболочку и изображения в том же браузере. На телефоне адрес вида `http://АДРЕС-КОМПЬЮТЕРА:8765/` — обычный незашифрованный HTTP: приложение остаётся доступно по сети и сохраняет записи в IndexedDB этого браузера, но установка PWA и service worker/офлайн-кэш недоступны. Веб-интерфейс показывает об этом предупреждение. Используйте такой адрес только в доверенной частной сети и не передавайте чувствительные данные. Для полноценной установки и офлайн-режима на телефоне потребуется HTTPS с сертификатом, которому доверяет устройство; данный комплект его не настраивает. При смене IP/порта браузер считает страницу новым источником, поэтому используйте один и тот же адрес.

В сборках начиная с v49 новая версия PWA загружается в фоне. Когда она готова, вверху появляется уведомление с кнопкой «Перезапустить». Страница не перезагрузится сама: закончите текущую работу, затем нажмите кнопку. Если уведомление закрыть, обновление применится при следующей ручной перезагрузке. Самое первое обновление со старых сборок до v49 может не показывать уведомление: старый интерфейс не умел его отображать, поэтому обновитесь обычной перезагрузкой страницы один раз.


## Обзор портфолио на главной странице (web v55)

Главная страница показывает распределение кейсов по статусам, наиболее часто используемые технологии и необязательные следующие шаги. Совет помогает заметить, например, что у проекта нет обложки, тега или заполненного раздела истории. Нажмите совет, чтобы открыть соответствующий кейс. Заполнять все поля не обязательно; приложение не ставит оценку и не ранжирует проекты. Для пустой библиотеки главная страница предложит создать первый кейс.

## Массовое управление проектами в веб-каталоге

В разделе «Мои проекты» отметьте чекбоксы на нужных карточках или включите «Выбрать показанные», чтобы выбрать весь список после текущих фильтров. Повторное нажатие снимает выбор только с видимых проектов: выделенные, скрытые фильтром, останутся выбранными. Панель сообщает их количество и отдельно указывает, сколько сейчас не видно. Нажмите «Снять выбор», чтобы очистить всё.

Команды панели добавляют выбранные кейсы в избранное, убирают их оттуда или удаляют. Избранное сохраняется автоматически. Удаление сначала показывает подтверждение с количеством. После удаления можно нажать «Отменить» в уведомлении в течение семи секунд; проекты восстановятся на прежние места вместе с прежним выделением.

## Предпросмотр и экспорт витрины

1. Отметьте кейсы, которые хотите показать, как избранные.
2. Откройте раздел «Витрина» и выберите редакционный, ночной или галерейный стиль HTML-страницы. Затем нажмите «Предпросмотр HTML». Встроенное окно показывает итоговый автономный файл на экране компьютера или телефона. Закройте его кнопкой или клавишей Escape; исходные кейсы от просмотра не меняются.
3. Кнопка «Скачать готовую витрину» откроет проверку состава: избранные кейсы, изображения, ссылки и включённые контакты автора. Просмотрите список и саму страницу; затем нажмите «Скачать этот HTML». Файл сохранится на устройстве и никуда не отправляется. Если позже вручную разместить или переслать файл, показанное в нём содержимое станет доступно получателям.

## Обложка и галерея проекта

В редакторе добавьте одну обложку и до десяти дополнительных изображений. Общая галерея ограничена примерно 6 МиБ сжатых медиа, чтобы резервные копии оставались переносимыми. Для обложки и каждого элемента галереи используйте слайдеры кадрирования по горизонтали и вертикали: предпросмотр сразу показывает, какая часть изображения попадёт в карточку. Для каждого элемента галереи задайте короткое описание того, что видно на экране: оно показывается под изображением и используется экранными дикторами. Стрелки меняют порядок изображений. Веб-версия автоматически уменьшает изображения до подходящего размера. Настольная версия сжимает добавленные детали в WebP. Исходные файлы остаются на устройстве, а готовые данные переходят в JSON и SQLite вместе с проектом.

Галерея отображается в подробностях проекта, автономном HTML-экспорте и обеих версиях приложения. Старые карточки без массива `gallery_images` продолжают открываться как раньше.

В веб- и настольном редакторах блок «История кейса» предлагает шесть необязательных подсказок: опишите задачу, свою роль, решение, процесс, результат и визуальные доказательства. Счётчик показывает только заполненность, не оценивая качество. Сохранение не требует заполнить эти подсказки; указывайте только факты, которыми можете подтвердить, и не придумывайте метрики. В веб-версии нажмите «Посмотреть структуру кейса», чтобы открыть список. В настольной версии список остаётся видимым в форме.

В окне галереи список изображений и настройки расположены рядом на широком экране и друг под другом на узком. При нехватке высоты прокручивайте содержимое колесом мыши или полосой; кнопки отмены и сохранения остаются внизу.

## Перенос и резервное копирование

### Настольная версия

Используйте меню «Файл», чтобы экспортировать JSON, CSV или Markdown. «Сохранить базу как…» позволяет сохранить копию SQLite в выбранное место. Храните JSON отдельно от рабочей папки, чтобы он пережил повреждение или потерю локальной базы.

CSV-экспорт добавляет апостроф перед текстом, похожим на табличную формулу (`=`, `+`, `-`, `@`), чтобы Excel и совместимые редакторы не выполняли пользовательское содержимое как формулы. Если CSV импортируется обратно в приложение, исходным переносимым форматом остаётся JSON.

### Браузерная версия

Откройте «Настройки и данные», выберите экспорт JSON и сохраните файл вне браузерного профиля. При импорте сначала показываются количество проектов и совпадения ID. Можно объединить данные, оставить локальные совпадения, импортировать совпадения как копии или полностью заменить библиотеку. Перед полной заменой веб-версия скачивает резервную копию.

JSON-копия содержит полный профиль, включая email, сайт и GitHub, даже если отдельные контакты скрыты на публичной витрине. Храните файл в приватном месте и не пересылайте без проверки содержимого. Folio не добавляет отдельное шифрование данных; защита зависит от учётной записи и устройства.

Не очищайте данные сайта браузера, пока не сохранили JSON: очистка профиля браузера удаляет локальные записи и черновики формы. Не оставляйте резервную копию на общедоступном устройстве.

## Черновики и приватность

Незаполненная форма браузерной версии автоматически сохраняется локально. Если закрыть форму или перезагрузить страницу, при следующем открытии она предложит восстановить черновик. Черновик не переносится в JSON и не синхронизируется с другими устройствами; после сохранения карточки он удаляется.

Карточки и изображения остаются в выбранном локальном хранилище. Для быстрого просмотра публичной демонстрации откройте https://altento.github.io/folio-portfolio/; для собственных данных используйте локальный запуск на компьютере или PWA в своём браузере. Автоматической синхронизации между устройствами нет, перенос выполняется через JSON.

## Если что-то не работает

- **Команда `python` не найдена.** Установите Python 3 и проверьте, что доступны Python и Tkinter; затем запустите BAT ещё раз.
- **Телефон не открывает страницу.** Проверьте, что телефон и компьютер подключены к одной Wi-Fi сети, серверное окно ещё работает, адрес содержит правильный IPv4 компьютера и порт `8765`, а Windows разрешила Python для частной сети.
- **Не открывается PWA без интернета.** Сначала откройте страницу онлайн и дождитесь полной загрузки; используйте тот же браузер, IP/домен и порт.
- **Не видно недавних изменений в приложении.** Перезагрузите страницу после подключения к сети: новая версия оболочки обновляется через service worker.
- **Нужно вернуть данные после сбоя или смены устройства.** Импортируйте последнюю JSON-копию. Настольная и браузерная базы независимы, поэтому экспортируйте данные с того устройства, где находится более свежая версия.

## Проверки разработчика

Запускайте проверки из корня проекта:

```powershell
python -m unittest discover -s tests -v
```

Для веб-логики из папки `web`:

```powershell
npm test
```

Браузерное приложение не требует сборщика или сторонних JavaScript-библиотек. Pillow используется настольной версией для локальных изображений.

## Управление списком с клавиатуры — desktop

В основном окне нажимайте Tab от поиска через фильтры к таблице проектов и дальше к кнопкам действий. Стрелки вверх/вниз выбирают строку, а карточка деталей обновляется вместе с ней. Shift+Tab возвращает к выбранной строке. Для работы с выбранным проектом переходите к «Изменить», «Дублировать» или другому действию.

## Визуальная галерея проектов — desktop v91

Под поиском найдите блок «Представление» и выберите «Карточки» для просмотра обложек, статусов, описаний, технологий и действий «Открыть кейс»/«Изменить». Колесо мыши прокручивает галерею даже когда курсор находится над текстом внутри карточки. Нажмите «Таблица», если удобнее сравнить поля в строках, сортировать по заголовкам и пользоваться стрелками клавиатуры. Выбор карточки синхронизируется с общей панелью действий и подробностями проекта. При сужении окна меньше 1120 px галерея автоматически становится одноколоночной; при дальнейшем изменении ширины размер обложек пересчитывается.



## Другие кейсы из карточки — Web/PWA v73

Внизу подробностей проекта показаны до трёх других работ из текущего портфолио — с обложкой, названием и типом. Порядок берётся из вашего ручного порядка проектов. Нажмите карточку или выберите её клавишей Tab и активируйте Enter/Пробел, чтобы открыть следующую работу без возврата в каталог. Escape закрывает окно подробностей и возвращает фокус к исходной карточке.

## Android-приложение для телефона

Тестовый APK и инструкция находятся в `mobile/`. Это оболочка общей веб-версии для Android; данные сохраняются локально на телефоне. Перенос с ПК и обратно выполняется вручную через JSON-файл: раздел «Данные» → «Скачать резервную копию» → передать файл на другое устройство → «Импортировать JSON». Синхронизация через интернет не настроена.

`mobile/folio-android-debug.apk` — тестовая debug-сборка. Её можно установить для знакомства с приложением, но нельзя считать выпускной версией для магазина. Перед релизом нужно настроить устойчивую подпись, проверить APK на реальном телефоне и подтвердить системный импорт/экспорт на целевых устройствах.


## Сохранённые представления каталога

В разделе «Проекты» настройте поиск, фильтры, сортировку и переключатель «Карточки/Список». Нажмите «Сохранить вид», задайте короткое имя и подтвердите. Вид сохраняется на этом устройстве. Выберите его в списке, чтобы вернуть весь набор настроек, включая режим отображения. Кнопка «Удалить» удаляет выбранную подборку. Старые подборки автоматически продолжают работать; если в них не был записан режим, останется выбранный сейчас режим.
