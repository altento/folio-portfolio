# Проверка Folio Web/PWA v161 и Windows WebView2 v164

Дата: 10.11.2026. Проверен локальный собранный Windows WebView2 EXE, который отдаёт локальные Web/PWA-ресурсы v161. Проверки выполнены в отдельном изолированном Chromium/Playwright-профиле; рабочая база пользователя не подключалась.

## Матрица интерфейса

Обзор, проекты, витрина и настройки проверены на 320×568, 390×568, 390×844, 768×900 и 1440×900: 20/20 состояний успешны. Для каждого состояния протокол содержит ожидаемый маршрут, размеры viewport и фактическую разметку.

- Горизонтальное переполнение: 0.
- Сломанные видимые изображения проектов: 0.
- Видимые касательные цели меньше 44 CSS px: 0.
- На ширинах 320–390 px минимальная измеренная подпись: 10 px.
- Ошибки браузера: 0.

## Потоки данных и офлайн

В отдельном синтетическом профиле создан проект, проверено сохранение после перезагрузки, редактирование, Undo после удаления и истечение периода восстановления с возвратом трёх демонстрационных карточек. Холодная офлайн-перезагрузка Service Worker показала три демо-записи без битых обложек. Пользовательская база не использовалась.

На телефоне закрытые панели фильтров и сохранённых представлений не занимают место и не показывают элементы управления. После раскрытия проверены доступные имена полей и действий.

## Регрессия и доступность

- Web/PWA: 85/85 автоматизированных Node.js-проверок.
- Python/SQLite: 97/97 проверок.
- Axe-core 4.14.0: десять состояний, 0 автоматических нарушений, 0 ошибок браузера; кандидаты `incomplete` дополнительно рассмотрены вручную по контрасту.
- Клавиатурная проверка: skip-link первый в Tab-порядке, перевод фокуса на main, Escape закрывает диалог и фокус возвращается к исходной кнопке.

Полный протокол и скриншоты: рядом в `result.json`, `run_product_flow_v161.py`, `effective-zoom-proxy-720x450/` и `projects-1440x900.png`. 720×450 — viewport-прокси, а не проверка системного масштаба.

## Границы результата

Проверка Chromium против локального EXE-хоста не заменяет ручное озвучивание Windows Narrator/NVDA и проверку нативного диалога файлов. Реальное устройство и TalkBack проверялись отдельно только в AVD; физический телефон и OEM file picker остаются открытыми внешними проверками.
