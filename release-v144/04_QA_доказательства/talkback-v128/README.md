# TalkBack accessibility tree — Android v128 — 05.11.2026

Проверка выполнена на Android Emulator API 36 с TalkBack 16 временно включённым через ADB. После сбора дерева служба отключена; исходное состояние эмулятора (accessibility disabled, список сервисов пуст) восстановлено и проверено.

На обзоре найдено 20 интерактивных элементов, в каталоге — 23, в форме проекта — 13. Каждый элемент имеет доступное имя в тексте, `content-desc` или подсказке поля; безымянных действий в проверенных состояниях — 0. Поля формы озвучиваемо именуются по назначению: название, краткое описание, дата, демо-ссылка, технологии и теги. Дамп каталога первоначально показывал пустой `text` у поля поиска, но поле имеет доступную подсказку «Поиск проектов».

Снимки и деревья трёх состояний находятся рядом: обзор, каталог, форма. Это подтверждает доступную структуру Android WebView при включённом сервисе; оно **не подтверждает качество фактической речи, жестовый проход, физическое устройство или системное увеличение**. Эти проверки остаются открытыми.

Во время прогона установлена сборка Android `versionName=0.2.2` (`versionCode=4`). Пользовательские настройки/контакты из раздела «Данные» в комплект доказательств не включались.

При первом запуске после обновления APK был виден штатный баннер новой версии. Нажатие «Перезапустить» открыло обзор без баннера; после перезагрузки Service Worker контролирует страницу, активен, ожидающего worker нет. Баннер не повторился, данные приложения при этом не очищались. Проверка ограничена этим экземпляром AVD.
