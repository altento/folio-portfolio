# Доступность мобильного диалога импорта — v146

axe-core 4.14.0 проверил диалог импорта на 390×568 и 320×568 CSS px. Проверены начальный фокус, Shift+Tab на границе диалога и возврат фокуса к кнопке после Escape. Нарушений WCAG A/AA в проверенных правилах не обнаружено. Подробный JSON и скриншоты находятся рядом.
