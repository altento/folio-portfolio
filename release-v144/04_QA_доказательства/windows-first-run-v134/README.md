# Windows first run v134 — 05.11.2026

## Цель

Проверить запуск свежей сборки Windows WebView2, когда в изолированном профиле ещё нет SQLite базы прежней настольной версии. В v133 нормальный ответ `404 No legacy portfolio` появлялся как ошибка загрузки в Chromium Console.

## Результат

- v134 отвечает на `/desktop-seed.json` кодом **204 No Content** и переводит оболочку на локальные демонстрационные записи.
- Первый экран показывает **3 демо-кейса**. Консоль Chromium: **0 ошибок, 0 предупреждений**.
- В изолированном `%TEMP%` профиле не создан `portfolio_data.sqlite3`; пользовательский `%LOCALAPPDATA%\Folio` и данные пользователя не использовались.
- Web/PWA v134 работает с Service Worker cache `folio-shell-v134-clean-desktop-first-run`.
- Python/SQLite regression: **91/91**; Web regression: **63/63**; Python и JavaScript syntax checks: PASS.
