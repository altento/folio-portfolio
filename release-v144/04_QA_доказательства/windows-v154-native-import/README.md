# Windows WebView2 v154: нативный импорт JSON

Дата: 07.11.2026. Проверена сборка `dist/folio-webview-v154/folio-desktop/folio-desktop.exe` в изолированном профиле `%TEMP%/folio-desktop-v154-native-picker-qa` на loopback-порту `41771`. Рабочий профиль и пользовательская база не открывались.

Через кнопку «Импортировать JSON» открылся системный диалог Windows. В нём был выбран только синтетический файл `служебные_файлы/qa_07-11-2026/windows-v154-backup/web-import/input-synthetic.json`. Предпросмотр показал один входящий проект, три текущих проекта, ноль совпадений ID. Выбран безопасный вариант «Добавить в портфолио»: приложение сообщило «добавлено 1, обновлено 0, пропущено 0, копий 0».

После перезагрузки WebView каталог по-прежнему содержал четыре проекта; синтетическая карточка `Synthetic cross-device import QA` видна в списке. Повторное открытие того же JSON после импорта корректно показало совпадение ID `901` с существующей карточкой; предпросмотр отменён, данные остались без изменений. Полная замена в этом нативном прогоне не выполнялась. Отдельный Chromium E2E с синтетическими данными ранее проверил резервную копию перед полной заменой.
