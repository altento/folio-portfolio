# Свежий аудит Web/PWA v152 — 07.11.2026

## Изолированная проверка

Проверка выполнена через локальную копию `web/` на `http://127.0.0.1:8768/` в отдельном временном Chrome-контексте. Профиль пользователя и его базы не открывались; весь CRUD выполнялся только на трёх автоматически загруженных демонстрационных карточках в новом профиле.

## Результаты

- HTTP 200; ошибок страницы и console — 0.
- Обзор, проекты, витрина и настройки открылись на пяти ширинах: 320, 390, 768 и 1440 CSS px, плюс два варианта высоты телефона (568 и 844 px). Во всех 20 состояниях ширина документа осталась равна ширине viewport; горизонтального переполнения нет.
- После принудительной загрузки отложенных изображений карточек все изображения декодировались без ошибки.
- Service Worker установился и управлял страницей; холодный reload при отключённой сети открыл dashboard с тремя примерами и всеми тремя изображениями обложек. `navigator.onLine=false`, ошибок загрузки нет.
- Мобильный трёхшаговый wizard виден при 390×844. Синтетический проект создан, пережил reload, отредактирован, удаление отменено и затем восстановлено штатным undo-окном; в конце остались только 3 исходных демо-записи.
