# Android AVD QA — Folio v156

Проверка выполнена 09.11.2026 на выделенном Android Emulator `FolioQA_API36`, устройстве `emulator-5554`, API 36. Установлен пакет `ru.folio.portfolio`, версия 0.3.19, `versionCode` 31, `targetSdk` 36. APK установлен через `adb install -r` поверх версии 0.3.18; приложение и пользовательские данные не удалялись и не сбрасывались.

## Результат

1. Первый запуск после установки показал штатное уведомление о доступном обновлении web-ресурсов.
2. Нажатие «Перезапустить» применило новую версию Service Worker; уведомление исчезло.
3. Открылся dashboard с тремя демонстрационными карточками.
4. XML UIAutomator после обновления содержит 107 узлов, 18 кликабельных элементов с доступным именем и 0 безымянных кликабельных элементов.
5. APK в телефонном ZIP совпадает по SHA-256 с отдельным APK; CRC ZIP проверен без ошибок.
