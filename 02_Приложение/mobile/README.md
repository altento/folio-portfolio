## Сборка исходников в Windows



Требуются Node.js/npm, JDK 21 и Android SDK (API 36, Build Tools 36.1.0). После установки зависимостей из этой папки выполните:



```powershell

npm ci

.\build-android.ps1

```



Скрипт использует `%USERPROFILE%\.cache\folio-android-sdk` и `%USERPROFILE%\.cache\folio-android-build-tools\temurin-unpack\jdk-21.0.13+9`; переменные системы и PATH не меняет. При самостоятельной установке SDK/JDK при необходимости скорректируйте локальные пути в `build-android.ps1`.



APK появится в `android\app\build\outputs\apk\debug\app-debug.apk`. Для открытия эмулятора/физического телефона включите USB debugging и установите APK средствами Android Debug Bridge либо скопируйте его на устройство. Выпускную подпись, ключ и публикацию нужно настраивать отдельно.
