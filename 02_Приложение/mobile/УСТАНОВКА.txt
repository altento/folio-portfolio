Установка folio на Android

1. Распакуйте архив на телефоне.
2. Откройте folio-android-debug.apk и подтвердите установку из выбранного источника, если Android спросит.
3. Запустите «folio». Данные остаются на устройстве; для переноса используйте экспорт/импорт JSON.

Сборка: 02.11.2026, Android debug на основе web/PWA v118. Настройки предупреждают, что приватный браузерный сеанс может удалить локальные данные после закрытия; для постоянной работы рекомендуется обычный профиль и регулярная JSON-копия вне профиля. Это предупреждение не заменяет отдельную проверку реального private mode. Web regression — 53/53, Python/SQLite — 81/81. Резервное копирование Android отключено: allowBackup=false, legacy backup rules и современные cloud/device-transfer правила исключают пользовательские хранилища. Перенос выполняется явным JSON-экспортом.
APK v118 собран, установлен поверх приложения на Android Emulator API 36 с сохранением данных и запущен; экран настроек визуально подтвердил новое предупреждение. Доказательство: `служебные_файлы/qa_02-11-2026/android-v118-private-storage/`. Физический телефон, реальная экранная клавиатура, TalkBack/TTS и private-mode поведение не проверялись.
Это debug-сборка для проверки, не для Google Play.
