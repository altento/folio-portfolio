## Что закрыто

- Web JSON экспорт и автоматическая резервная копия перед заменой портфолио сериализуются с общим пределом 64 МиБ.
- Web отклоняет нечисловые/небезопасные ID и порядок, некорректный тип `featured`; обложка ограничена 2 МиБ декодированных base64-байтов.
- SQLite как самостоятельная граница хранения проверяет реальную дату календаря, список до 40 технологий, поля технологии (название 60, категория 60, версия 40), управляющие символы и пустое название.

- Общий переносимый JSON fixture с кейсом, тегами, избранным, технологиями, обложкой и галереей проверяется desktop и web версиями.
