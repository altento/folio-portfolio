# Web responsive QA — v97

**Дата:** 02.11.2026  
**Результат:** пройдено по основным метрикам; обнаружено небольшое неудобство на коротком узком экране, см. ниже.

## Источник и изоляция

Порты 8765 и 8766 не слушали локально, поэтому использован отдельный временный статический сервер Python на `http://127.0.0.1:8767/`, корень — каталог `web/` текущего проекта. HTTP-ответ: 200. Сервер запускался отдельно, Chrome пользователя не использовался.

Прогон выполнен в новом временном Playwright-контексте с установленным Microsoft Edge (Chromium), без пользовательского профиля и с пустым origin-хранилищем. Отображавшиеся примеры приложения были в этом изолированном контексте. Пользовательские IndexedDB/localStorage и файлы проекта не менялись; в формы ничего не вводилось, сохранение/импорт/экспорт не запускались.

## Матрица

Проверены размеры 320×568, 390×844, 768×900, 820×900, 821×900, 1024×768 и 1440×900. На каждом — разделы «Обзор», «Мои проекты», «Настройки и данные» (21 проверка). На мобильных и планшетных ширинах до 820 px дополнительно проверена прокрутка до конца страницы (12 состояний). На каждой ширине открыта форма нового проекта, измерена геометрия диалога, затем форма прокручена до кнопок действий и закрыта через Escape (7 открытий и 7 закрытий).

## Результаты

- Все 21 состояния разделов открылись; выбранная навигация соответствовала разделу.
- Горизонтального переполнения не обнаружено: `document.scrollWidth` совпал с шириной viewport во всех состояниях.
- В точке 820→821 px навигация переключилась ожидаемо: при 820 px видна нижняя панель, при 821 px — боковая панель. На 1024 и 1440 px боковая навигация сохраняется.
- Нижняя панель не перекрывала последний элемент внизу прокрутки; нижний запас рабочего пространства равен 66 px.
- Диалог нового проекта оставался внутри viewport на всех семи размерах. После прокрутки кнопки «Отмена» и «Сохранить проект» попадали в видимую область. Escape закрывал каждую форму. В ширинах диалога горизонтального переполнения нет.
- Ошибок JavaScript, ошибок консоли и упавших сетевых запросов — 0.

### Наблюдение для 320×568

На первом экране каталога фиксированная нижняя навигация накрывает самый низ строки «Выбрать показанные» до прокрутки. Эта строка становится полностью доступной при небольшом прокручивании; внизу страницы последний элемент отделён от панели навигации 66 px запасом. Это не блокирует работу, но на коротком экране выглядит тесно.

В форме нового проекта при 320×568 нижние кнопки не находятся в первом кадре: длинную форму нужно прокрутить. После прокрутки кнопки видны целиком внутри окна. На 390×844 кнопки уже видны в исходном положении формы.
