# QA web/PWA v104 — offline navigation and favorite labels

Дата: 02.11.2026. Проверка выполнена в изолированном контексте Chromium на временной копии веб-ресурсов, размещённой под `/folio/`, как при публикации в подпапке.

## Проверенные сценарии

- Service Worker активен с cache key `folio-shell-v104-favorite-sort-clarity` и scope `http://127.0.0.1:8769/folio/`.
- При выключенной сети `/folio/?build=offline-v104#projects` загружает рабочую оболочку с сохранённого кэша. В каталоге заголовок сортировки — «Сначала избранные», флажок — «Только избранное».
- На ширине 390×844 CSS px страница каталога имеет `documentElement.scrollWidth = 375`, горизонтального переполнения нет.
- Неизвестный вложенный URL офлайн показывает экран «Нет подключения». Ссылка разрешается в зарегистрированный корень `/folio/`; нажатие возвращает к портфолио без сети. Страница fallback: ширина документа 390 px при viewport 390 px.
- Регрессионный набор web: 41/41.

## Кадры

- `mobile-offline-projects.jpg` — каталог и новый текст сортировки/фильтра на ширине 390 px в офлайн-режиме.
- `mobile-offline-fallback.jpg` — экран возврата из неизвестного пути в scope приложения.

## Ограничения

Это Chromium-эмуляция сети и размеров viewport, не физический телефон или Safari/iOS. Не выполнялись настоящий screenreader/TalkBack, системный zoom и увеличение шрифта.
