## Как повторить сборку

Запустите `build-android.ps1` из любой рабочей папки. Скрипт использует пути относительно своего расположения, локальный Temurin JDK 21.0.13, Android SDK API 36 и Build Tools 36.1.0. На время дочерней сборки он задаёт короткие `TEMP`/`TMP` и `jdk.net.unixdomain.tmpdir`, затем восстанавливает исходные переменные окружения и текущую папку. Полный вывод команды сохранён в `../android-gradle-build-v84.log`.

Gradle 8.14.3 успешно выполнил 93 задачи. Пакет APK: `ru.folio.portfolio`, версия `0.1.0`; подпись локальная debug. `apksigner verify` подтвердил подпись v2, проверка ZIP-выравнивания прошла. Размер и SHA-256 находятся в `results-v84-gradle.json`.

## Границы проверки

Это APK для локальной установки и проверки, не релизная сборка для магазина. Запуск и отображение главного экрана подтверждены на эмуляторе; физический телефон, другие версии оболочек Android и release-подпись пока не проверялись. Публичная публикация и облачная синхронизация не настроены.
