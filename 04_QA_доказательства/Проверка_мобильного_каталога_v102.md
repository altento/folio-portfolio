# Проверка мобильного каталога v102 — 02.11.2026

## Объём

Проверен браузерный каталог при 320×568 и 390×844 CSS px в изолированном профиле без Service Worker. Дополнительно проверены раскрытие фильтров клавиатурой, сохранение фокуса и состояния после фильтрации, создание и повторное применение сохранённой подборки, переход в desktop layout 1440×900. Android debug APK собран заново, установлен на Android Emulator API 36, данные тестового приложения очищены, сети отключены, после force-stop выполнен холодный запуск.

## Результаты

- Браузерный сценарий: PASS; HTTP 200, ошибок страницы и консоли нет.
- На 320×568 ширина документа равна viewport 320 px; карточка начинается на y=367 px (до оптимизации — y=442 px), над нижней навигацией видно 137 px карточки. На 390×844 карточка начинается на y=517 px, над навигацией видно 263 px.
- Фильтры и подборки по умолчанию закрыты на узком экране и доступны нативными раскрывающимися блоками. На 1440 px оба блока раскрыты, их summary скрыты стилями desktop.
- По Enter раскрываются фильтры. После выбора типа фильтр остаётся раскрытым, фокус сохранён на select, счётчик и результаты обновлены.
- Создание подборки «QA каталог v102» и её повторное применение восстановило тип «Веб-приложение»; блок подборок сохраняет открытое состояние.
- Минимальная высота цели выбора и кнопок вида — 44 px; подпись выбора на 320 px — 11 px. Горизонтального переполнения нет.
- Android debug APK собран успешно; SHA-256 `d563efc0c6d7476ee8a1fced524fea6a5d856c58446d645e7edbd75ef3fb56ae`. AVD API 36 очистил данные, Wi-Fi и mobile data выключены, установленный пакет обнаружен, cold launch foreground подтверждён, PNG-снимок валиден. APK signature v2 и zipalign 4 KiB — PASS.

## Границы доказательства

Проверялась эмуляция viewport и Android Emulator, а не физический телефон. В этом проходе не проверялись ландшафт, масштабирование текста Android, OEM file picker, VoiceOver/TalkBack, установка PWA по доверенному HTTPS. Android сборка является debug APK, не release-подписью.
