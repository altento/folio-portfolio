# Контраст web/PWA v97

- Источник: `http://127.0.0.1:8766/`
- Окружение: isolated headless Chrome context, 1440×1100; service workers blocked. Возможные демо-данные были только в эфемерной базе контекста. Импорт, формы сохранения и пользовательская база не затрагивались.
- Проверено: dashboard, projects, project detail, showcase, settings в светлой и тёмной темах; 10 состояний.
- Метод: видимые текстовые узлы, computed CSS foreground и ближайший непрозрачный solid background; WCAG contrast formula. Порог обычного текста — 4.5:1, крупного — 3:1. Для управляющих значков ориентир 3:1.

## Найденные проблемы

- **Projects, тёмная тема:** `Ctrl/⌘ K` — `#bcbcc0` на `#f4f4f2`, **1.72:1**, требуется 4.5:1.
- **Детали проекта, тёмная тема:** крестик `.detail-close` — `#25262a` на `#222327`, **1.04:1**, ниже ориентира 3:1 для значка управления.
- Белые подписи и номера на обложках поверх изображений/градиентов автоматически не оцениваются; требуется визуальная проверка реальных обложек.

## Контрольные элементы

- Акцентная «Создать проект»: `#202126` на `#c7f34b` — **12.51:1** в обеих темах.
- «Новый проект»: белый текст на `#25262a` — **15.12:1**.
- Disabled «Удалить» снижает opacity до 0.48. Неактивные элементы исключены из текстового контрастного требования WCAG, но выглядят существенно менее читаемо.
- «Локально»: `#686a70` на `#f6f6f4`, около **5.7:1**. Смысл индикаторов статуса продублирован числовыми значениями.

## Ограничения

- Полупрозрачность, изображения, градиенты, blend modes и текстовые тени требуют проверки по скриншотам.
- Фон изображения не проверялся поксельно; мобильный размер, zoom и все возможные данные не покрывались.
- Это отдельная автоматизированная оценка, не полное WCAG-соответствие.
