# Web responsive QA — v99

**Дата:** 02.11.2026  
**Версия источника:** service worker id `folio-shell-v99-compact-short-phone`.  
**Результат:** полная responsive-матрица пройдена; оба целевых элемента на 320×568 полностью выше нижней панели.

## Источник и изоляция

Текущий каталог `web/` сервировался отдельным Python static server на `http://127.0.0.1:8767/`. Перед запуском проверен `sw.js` с v99 cache id. QA выполнялся в новом изолированном Playwright-контексте с установленным Microsoft Edge/Chromium, без основного Chrome-профиля. Данные ограничены временным origin-хранилищем. Ввод и сохранение форм, импорт и экспорт не выполнялись; исходники не изменялись. После прогона сервер остановлен.

## Матрица и результаты

Проверены 320×568, 390×844, 768×900, 820×900, 821×900, 1024×768 и 1440×900. Для каждого размера открыты «Обзор», «Мои проекты», «Настройки и данные»: 21 состояние. На viewport до 820 px дополнительно снят низ страницы (12 состояний). Диалог проекта открыт на всех семи размерах, прокручен до кнопок и закрыт Escape.

- HTTP 200; выбранные разделы совпадали с активной навигацией.
- Горизонтального overflow нет. Ошибки JS, консоли и сетевых запросов — 0.
- Переход с нижней навигации на боковую корректен между 820 и 821 px.
- Диалог находится внутри viewport; кнопки действий доступны после прокрутки; Escape закрыл все семь диалогов.
- Последнее содержимое внизу мобильных страниц доступно над dock; рабочая область имеет 66 px нижнего отступа.

## Целевая проверка 320×568: каталог проектов

При начальной прокрутке верх нижней панели расположен на `y=504 px`.

- `.select-visible-control`: `y=446…490 px`, высота 44 px, зазор до dock — 14 px.
- `.result-summary` («3 проекта»): `y=485…503 px`; полностью выше dock, зазор 1 px.
- Оба элемента видны целиком и не перекрыты нижней панелью. Это подтверждено как DOM-замером, так и кадром `v99-projects-320x568.png`.

Вся `.results-line` занимает до `y=542 px`, потому что соседние дополнительные controls переносятся ниже; их часть может попасть под dock до прокрутки. Два заданных элемента — счётчик и массовый выбор — остаются видимыми. Остальные элементы доступны прокруткой.

## Артефакты

- `results.json` — все геометрические замеры, семь диалогов, ошибки и сводка.
- `run_responsive_v99.py` — сценарий для воспроизведения.
- 47 PNG: 21 viewport-кадр разделов, 12 мобильных кадров внизу страницы, 7 диалогов и 7 кадров диалога после прокрутки к кнопкам.

Эмуляция viewport не заменяет проверку на физическом телефоне.
