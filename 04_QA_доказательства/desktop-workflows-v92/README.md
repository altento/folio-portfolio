# Настольные потоки SQLite и JSON — 02.11.2026

Проверен запуск копии актуальной Tk-версии в отдельной временной папке с отдельной синтетической SQLite-базой, изначально содержащей три демонстрационных проекта. Пользовательская база не открывалась.

Через интерфейс созданы четвёртый проект, он найден точным поиском и отредактирован. JSON экспортирован в ту же временную папку. Затем файл импортирован обратно через предпросмотр: приложение показало четыре совпадающих ID, ноль новых записей; объединение сохранило локальные записи и не создало копий.

После операций независимое чтение SQLite подтвердило четыре проекта и `next_id = 5`; экспортированный JSON содержал те же четыре проекта и `next_id = 5`.

`results.json` содержит машинно-читаемые результаты. Снимки `01-search-edit.png`, `02-json-import-merge.png` и `03-search-result.png` показывают поиск/сохранённое редактирование, результат объединения JSON и итоговую карточку.

Этот проход не проверял удаление: прежние изолированные проверки удаления перечислены в матрице требований и предыдущих QA-отчётах. UI Automation по-прежнему не называет внутренние Tk-поля; NVDA/Narrator не запускались.
