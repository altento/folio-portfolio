# Проверка ручного переноса данных — v110

Дата: 02.11.2026. Область проверки: общий JSON-файл настольного приложения и web/PWA, ограничения изображений и пользовательские пояснения переноса.

## Что изменено

- Настольный импорт JSON проверяет версии и счётчики строгими целыми числами, отклоняет строки и булевы значения вместо тихого преобразования типов.
- Настольные кейсы и SQLite-сохранение согласованы с ограничениями браузерной версии для названия (90), описания (500), роли (120), результата (500), количества технологий, числа проектов и изображений, объёма вложенных изображений и суммарных пикселей.
- Запись `featured` принимается только как `true`/`false`; строка `"false"` больше не превращается в включённое избранное.
- Создан общий fixture `tests/fixtures/portable-transfer.json`. Настольный тест загружает его как JSON; web-тест читает его, нормализует и повторно сериализует, проверяя ключевые поля кейса и иллюстрации.
- Настройки web/PWA показывают три шага переноса файла, а экран предпросмотра импорта сообщает, сколько текущих кейсов будет удалено при полной замене.
- Service Worker обновлён до `folio-shell-v110-cross-device-transfer-contract`.

## Проверки

- `python -m py_compile main.py sqlite_storage.py` — PASS.
- `python -m unittest tests.test_portfolio tests.test_sqlite_storage -q` — PASS, 65 тестов.
- `npm test --prefix web` — PASS, 46 тестов.
- Android debug APK собран через `mobile/build-android.ps1`; проверка `zipalign -c -v 4` — PASS; `apksigner verify` подтвердил APK Signature Scheme v2.
- APK установлен на Android Emulator API 36, запущен и повторно открыт после force-stop при отключённой сети. `adb` подтвердил `not connected`, окно приложения активно.
