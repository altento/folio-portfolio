# Web/PWA: offline-перезапуск и адаптивность — v90

Дата проверки: 02.11.2026. Проверка проведена в отдельном изолированном браузерном контексте на localhost; данные активного браузерного профиля не затрагивались.

## Результаты

- Service Worker `folio-shell-v90-offline-chunks` активен и контролирует вкладку.
- Cache Storage содержит 22 ресурса оболочки, включая `native-startup.js`, иллюстрации и три обложки кейсов.
- При эмуляции отключённой сети страница перезагрузилась, отрисовала обзор портфолио и оставалась управляемой Service Worker; `navigator.onLine` вернул `false`.
- Проверены ширины 320, 390 и 1440 CSS px. Горизонтального переполнения нет; на мобильной ширине видна нижняя навигация, на desktop — основная боковая навигация.
- Ошибок JavaScript console после перезапуска без сети: 0.

## Границы

Это browser test на localhost и изолированном хранилище, а не установка PWA на физическом телефоне. Установка/обновление PWA на телефоне через обычный LAN HTTP и реальные экранные дикторы остаются отдельными пунктами приёмки. Скриншотный артефакт этого теста не сохранён; наглядное Android-доказательство холодного offline-повтора лежит рядом в `folio-v90-cold-offline.png`.
