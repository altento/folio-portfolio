# Web/PWA v73 — переход между кейсами и mobile QA

## Изменение

В окне подробностей кейса появился блок «Из вашего портфолио»: до трёх других проектов с обложками, в ручном порядке владельца. Кнопки доступны с клавиатуры. Переход обновляет содержимое открытого диалога, а Escape закрывает его и возвращает фокус к исходной карточке. В логике нет автосортировки или скрытой оценки качества.

Решение следует общему паттерну портфолио-сайтов, где после просмотра работы посетителю предлагают продолжить знакомство с другими проектами; например, Adobe Portfolio описывает блок More in This Collection ([официальное руководство](https://help.myportfolio.com/hc/en-us/articles/50072031736731-Anatomy-of-an-Adobe-Portfolio-website)). В folio выбор остаётся на усмотрение автора через его ручной порядок.

Также исправлена настоящая узкоэкранная проблема каталога: фиксированный минимум ширины body и переполненная строка действий давали горизонтальную прокрутку на 320 px. Минимум ширины снят, панель фильтров и действий теперь подстраивается под доступную ширину; интерактивные цели не меньше 44 px.

## Проверка

- Сборка: Web/PWA v73; Service Worker cache `folio-shell-v73-related-case-navigation-body-fit`.
- Каталог проверен на 13 размерах: 320×568, 320×844, 340×568, 340×844, 360×800, 375×812, 380×844, 390×568, 390×844, 420×612, 768×1024, 1024×768 и 1440×900. Условие — `documentElement.scrollWidth <= documentElement.clientWidth`, включая исключение зарезервированной ширины вертикальной полосы прокрутки.
- Dashboard, каталог, витрина и данные/настройки: 320×568, 390×844 и 1440×900 — без горизонтальной прокрутки.
- В карточке на 320×568 видны две обложки других кейсов; нажатие Enter открывает следующий кейс в том же диалоге; Escape закрывает и возвращает фокус к карточке этого кейса. Все пять кнопок действий в карточке имеют высоту 44 px.
- Service Worker v73 перезагружает приложение без сети; офлайн остаются доступны карточка, две связанные обложки и детали. Консоль и pageerror пусты; после теста соединение восстановлено.
- Проверка выполнена в новом изолированном Chromium-профиле с демонстрационными данными. Пользовательская база не открывалась, файл не импортировался, пользовательские правки не сохранялись.

## Ограничения

Эмуляция Chromium не заменяет приёмку на физическом телефоне. Экранный диктор и системное окно установки PWA здесь не проверялись.
