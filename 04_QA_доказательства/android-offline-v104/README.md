# Android debug v104 cold-offline QA

Дата: 02.11.2026. Gradle `assembleDebug` завершился успешно после сборки ресурсов из текущего web/PWA v104. APK v104 установлен через `adb install -r`; установленная рабочая область обновилась с v103, сохранив данные приложения. На AVD API 36 в момент запуска были включены airplane mode (`airplane_mode_on=1`) и выключен Wi‑Fi (`wifi_on=0`). После `force-stop` приложение холодно запустилось без сети и показало рабочую область.

В мобильном каталоге раскрыты фильтры: видно «Сначала избранные» в поле порядка и отдельный флажок «Только избранное». Это уточняет разницу между сортировкой и фильтром.

APK: 19 048 371 байт; SHA-256 `646413e5feca94e46495c294e8c942138e559da16628a2f15ff73053dd5accef`. `apksigner` подтвердил APK Signature Scheme v2; `zipalign -c 4` и проверка CRC прошли. Это debug APK, он не предназначен для Google Play.

Кадры:
- `folio-v104-cold-offline.png` — рабочая область после холодного офлайн-запуска.
- `folio-v104-favorites.png` — каталог с раскрытыми фильтрами и новыми подписями.

Ограничения: проверен только AVD API 36, не физическое устройство. TalkBack, системное увеличение текста и UIA не проверялись. В logcat встречались Chromium cache-index/tile-memory warnings, их влияние на реальный телефон остаётся непроверенным.
