# Проверка кадрирования обложек — v113

**Дата:** 02.11.2026

## Что добавлено

Для проекта появился общий параметр `cover_position` в формате `X% Y%`. По умолчанию — `50% 46%`, что сохраняет привычный кадр веб-карточки. В веб-редакторе доступны горизонтальный и вертикальный ползунки с живым предпросмотром; в Tk-редакторе — те же два ползунка. Одно значение применяется в карточках desktop и web/PWA, странице кейса, мини-карточках связанных кейсов, JSON-экспорте/импорте, SQLite и автономной HTML-витрине. Старые проекты без нового ключа загружаются с прежним кадром. Диапазон валидируется от 0% до 100%; схема SQLite не меняется, так как запись проекта хранится в JSON payload.
