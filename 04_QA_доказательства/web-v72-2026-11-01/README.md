# Web/PWA responsive QA — 2026-11-01

Проверена веб-сборка v72 в новом изолированном Chromium-контексте по адресу локального сервера `http://127.0.0.1:8766/`. Профиль теста пустой; основной профиль браузера и пользовательские данные не затрагивались.

## Результаты

- Проверены viewport 320×568, 360×800, 390×844, 768×1024, 1024×768 и 1440×900: горизонтального переполнения нет; боковая навигация корректно сменяется нижней на узких экранах.
- В 390×844 Service Worker имеет состояние `activated`; manifest подключён.
- На 320 px чекбокс выбора проекта имеет 20×20 px, но его label обеспечивает область нажатия 44×44 px. Остальные видимые активные элементы соответствуют проверенному размеру; служебный file input скрыт.
- Основной поток каталога: переход в «Проекты», поиск «CRM» возвращает 1 кейс и объявляет результат через live region; очистка возвращает 3 кейса; переключение «Список» включает `aria-pressed=true`.
- Проверены доступные имена видимых кнопок, ссылок и полей: элементов без имени не обнаружено.
- В изолированном профиле использованы только демонстрационные данные; ничего не импортировано и не сохранялось.

## Ограничения

Это автоматизированная эмуляция Chromium, а не физическое устройство. Не проверялись установка через диалог операционной системы, реальный сенсорный ввод, VoiceOver/TalkBack/экранный диктор и сеть с нестабильным соединением. Для финальной приёмки желательна ручная проверка на телефоне.
