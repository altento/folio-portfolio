# Web responsive QA — v98

**Дата:** 02.11.2026  
**Срез:** service worker cache id `folio-shell-v98-csv-and-contrast-safety`.  
**Результат:** responsive matrix пройдена; отдельный узкий экран проверен дополнительно.

## Источник и изоляция

Порты 8765/8766 относятся к другим локальным сессиям; текущая v98 проверялась отдельным статическим сервером Python на `http://127.0.0.1:8767/`, корень сервера — каталог `web/` этого проекта. До прогона подтверждён ответ HTTP 200 и cache id v98. Сервер 8767 после QA остановлен.

Запуск был в новом изолированном Playwright-контексте с установленным Microsoft Edge/Chromium и пустым origin-хранилищем. Окружение Playwright MCP было занято другим профилем, поэтому использован отдельный Edge runtime, не основной Chrome пользователя. Формы не заполнялись; сохранение, импорт и экспорт не вызывались. IndexedDB/localStorage ограничены временным браузерным контекстом; исходники проекта не менялись.

## Матрица

Размеры: 320×568, 390×844, 768×900, 820×900, 821×900, 1024×768, 1440×900. На каждой ширине проверены «Обзор», «Мои проекты» и «Настройки и данные»: 21 состояние. Для viewport до 820 px дополнительно снят низ страницы: 12 состояний. На всех 7 ширинах открыта форма нового проекта; измерены рамки, прокручиваемость и кнопки; форма прокручена до конца и закрыта Escape.

## Результаты

- HTTP 200; все 21 состояния и соответствующая активная навигация открылись.
- Горизонтального overflow нет во всех viewport и состояниях диалога. Ошибок JS, консоли и сетевых запросов — 0.
- На 820 px используется нижняя навигация, на 821 px — боковая. Переключение между ними корректно.
- Формы проекта остаются в границах viewport. На всех семи размерах кнопки действий видны после прокрутки диалога, а Escape закрывает его. Горизонтального переполнения диалога нет.
- Внизу страниц контент доступен над нижней навигацией; мобильный нижний отступ — 66 px.

### Целевая проверка: проекты, 320×568

Строка «Выбрать показанные» полностью размещена выше нижней панели уже при начальной прокрутке: границы элемента `y=446…490 px`, верх панели `y=504 px`, зазор — 14 px. Размер интерактивной строки — 44 px. Проверено визуально по кадру `v98-projects-320x568.png` и геометрии DOM.

Сразу ниже селектора счётчик проектов близок к верхней границе панели и визуально тесно соседствует с ней. Сам селектор и его текст не перекрыты; остальные результаты доступны прокруткой. Это остаточное уплотнение первого экрана на 320×568, а не горизонтальное переполнение.
