# folio — локальное портфолио проектов



Настольное приложение для ведения проектов и браузерная PWA-витрина для компьютера и телефона. Данные остаются на устройстве: настольная версия хранит их в SQLite, каждый браузер — отдельно в IndexedDB. Автоматической синхронизации между ними нет; перенос выполняется через JSON.



В настольном коде модели и операции над портфолио вынесены в `portfolio_core.py`; Tk-интерфейс остаётся в `main.py`, который повторно экспортирует классы для совместимости. SQLite-контракт находится отдельно в `sqlite_storage.py`. Этот разрез также подготавливает поэтапную оценку Qt; действующий запуск пока открывает Tk-приложение.

## Запустить на компьютере



1. Распакуйте сдачный ZIP в папку, в которую разрешено сохранять файлы.

2. Для запуска готовой Windows-версии Python не нужен: откройте `02_Приложение/folio.exe` двойным щелчком или запустите `02_Приложение/Запустить приложение.bat`. В рабочей копии исходников готовый файл находится в корне проекта как `folio.exe`; `dist/folio.exe` может оставаться прежней сборкой, пока открыты её ранее запущенные экземпляры.

Для запуска исходного кода установите Python 3 и зависимости для обложек:

   `python -m pip install -r requirements.txt`

3. В сдачном ZIP исходный код запускается через `02_Приложение/Запустить приложение.bat`; в рабочей копии используйте `Запустить приложение.bat` или `python main.py`.



В исходном запуске база `portfolio_data.sqlite3` создаётся рядом с `main.py`; в автономном EXE она хранится в `%LOCALAPPDATA%\Folio`, поэтому не теряется во временной папке распаковки. Если рядом с исходным приложением есть прежний `portfolio_data.json`, оно переносит его в SQLite и оставляет JSON на месте. При первом запуске без данных появляются три демонстрационных кейса. Перед добавлением своих работ просмотрите примеры и замените или удалите ненужные.



## Открыть в браузере и на телефоне



1. На компьютере запустите `web/Запустить веб-версию.bat`.

2. На компьютере откройте [http://127.0.0.1:8765/](http://127.0.0.1:8765/).

3. Для телефона подключите оба устройства к одной частной Wi-Fi сети. Узнайте IPv4-адрес компьютера и откройте на телефоне `http://АДРЕС-КОМПЬЮТЕРА:8765/`.



Для локального запуска телефона через HTTP браузер ограничивает установку PWA и офлайн-кэш. Публичная статическая демонстрация доступна на GitHub Pages: https://altento.github.io/folio-portfolio/.



В защищённом контексте новые версии PWA устанавливаются в фоне; приложение показывает баннер обновления и ждёт нажатия «Перезапустить». Веб-формы поддерживают структурированную историю кейса и теги-чипы; есть сохранённые подборки фильтров, массовые действия, избранное и автономная HTML-витрина. Мобильная доводка v72 улучшила каталог на коротких экранах; v73 добавила переходы между связанными кейсами; v74 защищает полную замену портфолио резервной копией до сохранения, а настольный JSON-экспорт — от перезаписи активной базы; v75 переместила избранный кейс до сводных метрик; v78 исправила пробелы в адаптивном заголовке; v79 сделала мобильное предупреждение компактнее; v80 уплотнила hero на телефонах до 380 px. Настольная v91 добавила адаптивную галерею проектов и закреплённые действия в коротких окнах. PWA v86 улучшила контраст и доступные имена; v87 добавила предпросмотр автономной HTML-витрины; v88 исправила его переполнение на 320 px. Поле `tags` в JSON не менялось.



## Что умеет приложение



- Создавать, редактировать, дублировать, удалять и сортировать карточки проектов.

- В настольном приложении переключаться между визуальной галереей проектов и сортируемой таблицей; галерея перестраивается в одну колонку при узком окне.

- Хранить контекст задачи, решение, процесс, роль, результат, метрики, технологии и теги.

- Добавлять и удалять теги как отдельные чипы в веб-форме; вводить список через запятую или клавишей Enter, выбирать существующие подсказки.

- Подсказывать необязательную структуру истории кейса и показывать заполненность без оценки качества.

- Добавлять локальную обложку и до десяти описанных изображений галереи (общий объём галереи по-прежнему ограничен примерно 6 МиБ).

- Искать и фильтровать проекты, сохранять до 12 подборок, отмечать избранные по одному или массово и собирать из них автономную HTML-витрину.

- Выбирать отдельные или показанные после фильтрации проекты, удалять выбранные с подтверждением и вернуть удаление в течение семи секунд.

- Экспортировать и импортировать JSON для резервного копирования и ручного переноса между компьютером и телефоном; настольная версия также выгружает CSV и Markdown.



Пользовательские записи и изображения не передаются на сервер. База настольного исходного запуска находится рядом с `main.py`, а standalone EXE — в `%LOCALAPPDATA%\Folio`; браузерные данные принадлежат профилю и источнику конкретного браузера. Регулярно сохраняйте JSON-копию вне папки приложения и браузерного профиля.

## Web/PWA v74 — безопасная замена и резервная копия



При полной замене портфолио резервное копирование начинается до записи в IndexedDB. Если браузер не может подготовить скачивание, замена отменяется; если данные успели измениться до сохранения, приложение просит повторить импорт. На desktop JSON-экспорт защищён от записи поверх активной SQLite/JSON-базы и выполняется через атомарную замену файла. В форме и импорте запрещены ссылки, содержащие имя пользователя или пароль.



Изолированный Chromium воспроизвёл отказ `URL.createObjectURL` и подтвердил неизменность исходных карточек и revision; штатная ветка скачала `folio-before-import.json` до сохранения трёх проектов.
